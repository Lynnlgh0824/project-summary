# Project Summary - 产品文档

> Version: 1.0 | Last Updated: 2026-06-01

---

## 1. 产品愿景

**一句话定位**: 开发者的轻量级项目日志管理工具。

帮助开发者系统化记录项目经验、追踪工作进展、沉淀技术知识，告别"做完就忘"的恶性循环。

---

## 2. 目标用户画像

### 个人开发者
- **场景**: 日常开发、Bug 修复、功能迭代
- **需求**: 快速记录工作日志，不打断心流
- **痛点**: 写日志太麻烦，坚持不下来

### 技术负责人
- **场景**: 多项目并行管理、进度汇报
- **需求**: 统一视图查看所有项目进展
- **痛点**: 项目多了记不住每个的细节

### 学习者
- **场景**: 学习新技术、做练手项目
- **需求**: 记录学习笔记和代码片段
- **痛点**: 笔记散落各处，找不到之前的解决方案

## 4. 用户旅程

### 日常记录

```
打开页面 → 选择项目 → 点击"新建日志"
    → 输入标题 + 内容 + 选择标签 → 保存（<30秒）
```

### Git 集成

```
提交代码 → 自动捕获变更 → 生成日志草稿
    → 编辑补充说明 → 保存
```

### 进度回顾

```
打开页面 → 切换到统计视图 → 查看日志趋势
    → 查看标签分布 → 导出周报
```
